设备管理

一台电脑（客户端）上可以挂好几个「设备」：开着的安卓模拟器、 USB 插着的实体手机。账号和角色是指派到设备上的 —— 因为真正在跑游戏的是设备， 不是那台电脑。后台的所有设备操作都不是后端直接做，而是给那台客户端下发指令： 它执行完把结果报回来，所以按钮点完的反馈是「已下发」，结果会出现在下面的设备块里。

新增设备的完整流程（按页面从上往下点一遍就行）：
  1. 在要挂设备的那台电脑上先启动客户端（agent.py），让它的心跳上来。
  2. 如果是实体手机：用 USB 插好，手机上点「允许 USB 调试」（没授权前 adb 看不到它）。
  3. 在对应电脑的块里点 「扫描 ADB 设备」，等结果回来。
  4. 扫到的设备会出现在「扫到但还没登记」列表里，点它的 「添加」 入库。
  5. 实体机接着点 「覆盖成横屏」（不覆盖就没法跑 —— 见下面的说明）。
  6. 给它 指派账号 / 角色，再点 「发现角色」 把游戏里的角色名读回后端。

关于「实体机必须覆盖横屏」——这是实测结论，不是保险起见：
  • 手机原生竖屏是 1080×2400，进游戏横过来之后截图是 2400×1080。
  • 而本项目的所有点击坐标都是写死的 1920×1080（模拟器就是这个尺寸）。
  • 实测下发 adb shell wm size 1080x1920 覆盖后，截图变成 1920×1080， 游戏 UI 与模拟器逐像素一致 —— 验证方式是 OCR 找到「批阅」按钮在 (1229,888)， 与代码常量 BTN_JUNQING 完全相同。
  • ⚠ 覆盖会改你手机的逻辑分辨率（整个系统都会变横屏），拔线前点一下 「恢复原生」，否则手机桌面会一直是横的。重启手机也能恢复。
  • 覆盖是「竖屏基准」写法：写 1080x1920 而不是 1920x1080 —— 系统旋转时宽高会互换，写反了会得到一张 1920 宽的竖图。
